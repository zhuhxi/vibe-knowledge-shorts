# 自制音效库（版权自有，可商用、可再分发）
由 make_sfx.py 程序合成（plotome：「最省事的是让 AI 自己做音效，大部分时候也够用」）。改参数后重跑即可再生成。

| 文件 | 用在什么时刻 |
|---|---|
| 叮_出现 | 对勾、答对、关键数字落定 |
| 叮_低 | 片名、重要结论 |
| 嘀_计数 | 数字滚动的每一跳 |
| 咔_开关 | 拨开关、点击 |
| 嗖_滑入 | 卡片 / 稿子滑入、转场 |
| 咚_重音 | 大揭晓（更笨、152 层、一千层） |
| 啪_盖章 | 印章、档案卡落定 |
| 沙_纸张 | 稿子翻动、落下 |
| 刷_写字 | 红笔写字 |
| 啵_气泡 | 对话气泡弹出 |
| 嗡_错误 | 答错、✗ |
| 升_蓄力 | 揭晓前的上扬 |
| 嗒_多米诺 | 一个个倒下 |
| 闪_金光 | 金线、加号亮起 |
| 轰_碎裂 | 推倒重来、崩塌 |
| 滴_倒数 | 3、2、1 |

用法规矩（实测比特新语：平均每 1.2–1.5 秒一个音效/重音）：
- 按画面动作的时刻挂音效，音量比人声低 12–18 dB，不能盖过旁白
- 同一个意思用同一个音效（和配色一样，一个声音一个意思）
