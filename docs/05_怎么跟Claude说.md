# 怎么跟 Claude Code 说

整个片子的代码都是让 [Claude Code](https://claude.com/claude-code) 写的。我负责选题、定方向、挑毛病，它负责写 Remotion 代码、渲染、截图自查。

## 第一次
```
我想做一条 Vibe知识大赏 风格的 1 分钟竖屏知识短片，题目是「XXX」。
照 docs/02_制作流程.md 的 11 步做，模板在 template/。
先只做第 1–3 步：事实表 + 找形象 + 字幕稿，给我看了再动画面。
```

## 改画面：先说爆款怎么做的
```
开头第一秒字太小，抓不到重点。
先找一条爆款的开头是怎么处理的，引用给我看，再改。
```

## 加梗
```
太严肃了不好玩。照 docs/03_笑点手册.md，给我 3–5 个梗，
每个写明用的哪招、对标哪个爆款原句。我挑完你再做，先做一个 5–10 秒的片段给我看。
```

## 审片
```
派一个没参与制作的 subagent，只给它每秒一帧的联系表 + 字幕稿 + 事实表，
按 9 个维度打分，告诉我最差的 3 项。
```

## 省时间的小技巧
- **看帧别逐帧渲染**：`./stills.sh 3 10 25` 一次出一张联系表。
- **草稿用半尺寸**：`--scale=0.5 --muted`。
- **每一版都 git commit**，改坏了随时能退回去。
- **用户的原话要它记下来**，比如「小字没人看」「别让我久等」。下次就不会再犯。
- 仓库里的 `skill/vibe-video/SKILL.md` 可以装成 Claude Code 的 skill：放到 `~/.claude/skills/vibe-video/`，之后输入 `/vibe-video` 就会照这套流程走。
