# 发布：封面和三平台文案

## 封面（`src/Cover.tsx`）
出三种尺寸：16:9（1920×1080）、4:3（1440×1080）、3:4（1080×1440）。
小红书会把封面按视频比例裁成 4:3，所以要单独传一张 4:3 的。

封面内容 = 片名卡上的问题 + 一个反常识钩子 + 底部一行数据来源小字。

## 文案模板
| 平台 | 标题 | 正文 |
|---|---|---|
| B 站 | 「Vibe知识大赏｜问题？数据里的 3 条规则」 | 分区选「知识」；10 个标签，带活动话题「vibe知识上新啦」；简介写规则摘要 + 参考文献 + 配乐名；置顶评论放一个互动问题 |
| 抖音 | ≤30 字 | 带 #vibe知识大赏 等 5 个话题，加入官方活动 |
| 小红书 | ≤20 字 | emoji + ①②③ + 5 个话题 |

三个平台都勾上「AI 生成」声明。

## 发出去之后
- 第一小时回评论，每条两三句话就够。
- 配乐被识别侵权，就换上只音效版。
