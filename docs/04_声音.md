# 声音：配乐 + 音效

## 配乐
- 用赛道里大家常用的曲子，节奏一致，观众有熟悉感。我们用的是 B 站上的《Claude Opus 5.5の小曲》（112.9 BPM）。**仓库不附带配乐**：自己找好放到 `template/music/bgm.m4a`，版权自己核实。
- **测出 BPM，算出小节长度**：60 ÷ 112.9 × 4 = 2.126 秒一小节。
- **让曲子的「起势」落在片名卡上**：曲子第 17.01 秒起势，从第 11.81 秒起播，起势就落在片子的 5.2 秒。
- **时间网格**：`B(k) = 5.2 + 2.126 × k`。每句字幕占一小节，每 4 小节换一个段落或一条规则。

## 音效（`sfx/`，16 个，程序合成，版权自有）
- 只挂在大事件上：片名卡、章节、数字砸下、揭晓、盖章、气泡弹出。
- 同一个意思用同一个音效，跟配色一样，一个声音一个意思。
- 在 `audio_mix.py` 里写挂点：`cue(B(4) + 0.6, "啪_盖章", -3)`（时间、音效名、dB）。
- 冷停顿的梗后面**不要放音效**，安静本身就是笑点。

## 混音
```bash
python3 audio_mix.py      # → public/audio/mix.wav（配乐版）和 sfx_only.wav（只音效版）
ffmpeg -i out/raw.mp4 -af loudnorm=I=-14:TP=-1.5 -c:v copy out/成片.mp4
```
- 配乐 ×0.85 + 音效；配乐开头淡入 0.6 秒，结尾淡出 2.5 秒。
- 再出一版**只音效版**：平台识别到配乐版权时，换上它，配乐用平台曲库里的。
