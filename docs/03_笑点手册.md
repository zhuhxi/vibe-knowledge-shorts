## 七个手法（每条都附原句）

1. **把假设变成有离谱动机的人**（毕导）
   - 原句：「司机个个都是 timing 大师，拥有无视一切路况绝对准时到站的能力」「前面的司机是从武汉来技术扶贫的，后面的师傅肚子疼中途下车上了个厕所」
   - 做法：抽象条件 → 一个有具体、荒唐理由的角色。
2. **把潜规则直接说出口**（包仔）
   - 原句：「非会员购买卡包，需要观看一个广告」
   - 做法：现实里被包装起来的套路，让角色一本正经地讲出来。
3. **层层加码**（包仔）
   - 原句：会员 → 广告 → 弹窗 → 硬卡会员 → 超级硬卡会员
   - 做法：每过一关就多一个更离谱的关卡，主角的反应保持朴素。
4. **冷停顿 / 「没了」**（光子）
   - 原句：「MK12：由知名现代步枪改装而来的半自动……没了」
   - 做法：前面铺得很长，后面突然只剩一两个字，留白就是笑点。
5. **先戳穿观众，再反转成自嘲**（毕导）
   - 原句：「你肯定是那种股票亏了就在群里喊的人」→「但其实不是，我股票没涨」；「什么？你说你没有朋友？那我现在就是你的朋友了！」
6. **具体到荒唐的小细节，最好接一个人人知道的文化梗**（毕导）
   - 原句：「骆宾王就有 1 个朋友，可能还有 3 只鹅」
7. **用一句人生感悟收尾**（毕导）
   - 原句：「快车的快乐抵消不了慢车的漫长，人生也是」
   - 做法：把知识点突然升华到生活，半认真半玩笑。

## 用之前自查
- 笑点必须就是知识点本身，删掉笑点，知识也就断了。
- 角色要一本正经，不要自己先笑；越认真越好笑。
- 要具体：写「3 只鹅」，不写「几只动物」。
- 节奏：铺垫 2–3 拍，笑点 1 拍，后面停半拍不说话。

## 实战：《诱饵价格》里用上的 5 个梗
讲的是「诱饵效应」：咖啡有中杯 ¥12、大杯 ¥18 / 600ml、超大杯 ¥18 / 800ml。

| 梗 | 用的手法 | 屏上怎么做 |
|---|---|---|
| 顾客问「大杯 是卖给谁的？」，店员面无表情：「大杯不卖。是用来让您买超大杯的。」 | 2 说出潜规则 | 两个对话气泡（`kit.tsx` 里的 `Bubble`），不出字幕 |
| 顾客：「那我偏要大杯！」店员：「……」停一拍，「系统里没有这个按钮。」 | 3 层层加码 | 「……」单独出现 0.6 秒，再补后半句，配一声「嗡_错误」 |
| 超大杯的介绍卡一行行弹：800ml / 同价 ¥18 / 超值之选 / 店长推荐 / 人生首选；大杯只有「600ml。」，停半拍出灰字「（没了）」 | 4 冷停顿 | 长的那张每行配一声「叮」，短的那张后面什么声音都不放 |
| 没人选的印刷版：「没人选我 但我一直在上班」→ 被拿掉：「那我下班了」→ 套餐销量暴跌，套餐喊：「你回来上班！」 | 1 拟人 | 气泡长在那张订阅单上，跟着它一起飞走 |
| 结尾彩蛋：一张合照，你和一个「P 丑了的你」；字幕「所以合照 带个像你但更丑的朋友」 | 7 人生感悟收尾 | 出处：Ariely《怪诞行为学》第 1 章的照片实验 |

自查：每个梗删掉，知识点也就断了。这才是对的梗。
